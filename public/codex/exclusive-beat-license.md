# Exclusive Beat License

**A Codex document provided by Astra Matrix, Inc.**

An exclusive beat license transfers exclusive rights to use a producer's instrumental to a single artist — the producer stops licensing it to others going forward — while terms define ownership, publishing, royalties, and credit. Distinct from a non-exclusive lease.
