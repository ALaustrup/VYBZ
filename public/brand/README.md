# VYBZ brand assets

Official VYBZ marks used by the web app, PWA, and native wrappers (**Beta-0A**).

## Files

| File | Use |
|------|-----|
| `logo.svg` / `logo-white.svg` | Primary lockups (dark / light-on-dark surfaces) |
| `logo-black.svg` | Print / light surfaces (also Codex print header) |
| `logo-on-white.svg` | Alternate light-surface lockup (asset present; prefer `logo-black` in app) |
| `icon.svg` | App / PWA glyph |

Prefer `/brand/*` paths from the Vite app. In-app `Wordmark` may render a text
lockup where an image is not required. Keep exports consistent with the Astra
Matrix brand kit when refreshing marks.
