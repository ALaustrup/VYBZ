# VYBZ brand assets

Official VYBZ marks for the web app, PWA, social previews, and native wrappers.
Product: **release operating system for independent music** — Find Yours.
Promise: **Everything between finished and released.** Domain: [vybz.cloud](https://vybz.cloud).

## Files in this folder

| File | Use |
|------|-----|
| `logo.svg` / `logo-white.svg` | Primary lockups (dark / light-on-dark surfaces) |
| `logo-black.svg` | Print / light surfaces (also Codex print header) |
| `logo-on-white.svg` | Alternate light-surface lockup (prefer `logo-black` in app) |
| `icon.svg` | App / PWA glyph (waveform mark) |

## Site-wide launch assets (repo `public/`)

| Path | Use |
|------|-----|
| `/favicon.ico` | Legacy browsers / Google SERP favicon |
| `/favicon.svg` | Modern browser tab icon |
| `/favicon-64.png` | PNG fallback tab icon |
| `/icons/icon-192.png` | PWA / Android |
| `/icons/icon-512.png` | PWA / schema.org logo |
| `/icons/maskable-512.png` | Adaptive Android icon (safe padding) |
| `/icons/apple-touch-icon.png` | iOS home screen |
| `/og.png` | Open Graph + Twitter card (1200×630) |

Prefer `/brand/*` paths from the Vite app for in-product lockups. Keep exports
consistent with the Astra Matrix brand kit when refreshing marks.
