# VYBZ brand assets

Official VYBZ marks used by the web app, PWA, and native wrappers.

## Files

| File | Use |
|------|-----|
| `logo.svg` / `logo-white.svg` | Primary wordmark lockups in the shell |
| `logo-black.svg` / `logo-on-white.svg` | Print / light surfaces |
| `icon.svg` | App / PWA glyph |

Prefer `/brand/*` paths from the Vite app. Keep exports consistent with the
Astra Matrix brand kit when refreshing marks.
