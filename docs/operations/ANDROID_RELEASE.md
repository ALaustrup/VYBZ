# Android release guide (Phase 6 / Masterplan 2.A)

**Product:** VYBZ for Android · `applicationId` / `appId` **`cloud.vybz.app`** · version **1.1.0**  
**Exit gate:** [`docs/architecture/PHASE6_EXIT_GATE.md`](../architecture/PHASE6_EXIT_GATE.md)

## Build

```bash
npm run build:web
npm run sync:android          # Capacitor copy + update
npm run build:android:apk     # assembleDebug
npm run build:android:aab     # bundleRelease (signed if key.properties present)
npm run smoke:android:apk     # records APK hash stub or real SHA-256
```

Artifacts:

- Debug APK: `android/app/build/outputs/apk/debug/*.apk`
- Release AAB: `android/app/build/outputs/bundle/release/*.aab`
- Hash table: `android/signing/APK_HASHES.json` (generated by smoke)

## Signing

1. Generate keystore under `android/keystore/` (gitignored) — see `android/keystore/README.md`
2. Copy `android/key.properties.example` → `android/key.properties` (gitignored)
3. `bundleRelease` / `assembleRelease` picks up signingConfigs automatically

**Never commit** `*.jks`, `*.keystore`, `key.properties`, or `google-services.json`.

## Deep links

| Scheme | Example |

| Custom | `vybz://release/{id}` |

Intent-filters live in `AndroidManifest.xml`. App Links `assetlinks.json` verification is post-alpha.

## Push (FCM)

- Code path: `src/platform/push/deviceToken.ts` — registers + stores token locally
- **No server send** in Phase 6
- Requires local `android/app/google-services.json` (not committed) for real FCM

## Offline

- Credits drafts / session: sealed preference store (`securePreferences`)
- Upload queue: `src/platform/sync/uploadQueue.ts` with retry + progress
- Mutations: existing `mutationQueue` (flush when online)

## Play Console

Not required for alpha sideload. Internal testing track comes after first signed AAB + Play App Signing.
