# Iconography

> Restrained geometric icons for Suite wayfinding.

## Principles

- **Geometric, not illustrative** — simple strokes; consistent optical weight.
- **One metaphor per product** — Home, Studio, Prepare, etc. stay recognizable.
- **Status ≠ decoration** — severity icons for findings; no emoji in chrome.
- **Size scale** — rail 20–24px; inline 16px; avoid oversized ornamental icons.
- **Color** — inherit text/fog; accents only when encoding product or severity.

## Rules

- Prefer an existing icon set already in the repo over new packs.
- Do not mix filled and outline styles in the same rail without hierarchy reason.
- Watermark / security icons must not imply “unbreakable.”
- Empty states may use a quiet geometric mark — not mascot clutter.
