# Color

> Shared palette + product accents. Precision on graphite; expression on stage.

## Shared palette

| Name | Role |
|------|------|
| Abyss | Deepest background |
| Graphite | Panels, rails, sheets |
| Slate | Borders |
| Fog | Secondary text |
| Snow | Primary text |
| Cyan | Brand default |
| Success green | Pass / ready |
| Warning amber | In progress / caution |
| Danger red | Secure / error |
| Info ice | Prepare / cool status |

Avoid purple-on-white defaults, cream-serif terracotta tropes, and broadsheet
hairline newspaper layouts as brand defaults.

## Contrast

Meet WCAG AA for text on abyss/graphite. Accent is wayfinding — not body text
color. Error/success states must not rely on color alone (icon + label).
