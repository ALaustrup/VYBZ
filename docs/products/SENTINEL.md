# VYBZ Sentinel

> Authoritative product brief. Accent: **red**. Honest watermark language.

## Purpose

Secure prerelease sharing: rooms, signed access, watermarked previews, and
provenance — marketed only to demonstrated capability.

## Customer

Artists and labels who need to share unreleased audio with A&Rs, managers, or
collaborators without pretending leak-proof immortality.

## Jobs

- Create secure rooms with invite / revoke
- Limit play and download; time-box access
- Apply / detect watermarks; record ledger events
- Tie provenance manifests to release assets

## Data sketch

`secure_rooms` · `secure_*` access grants · `watermark_manifests` ·
`provenance_manifests` · existing watermark / ledger Edge functions.

## Cost behavior

Limited secure room on Free; expanded sharing on Creator+. Advanced watermark /
managed detect may be usage-backed with reservation. Prefer Engine-local apply
when possible.

## Copy one-liner

**Share before release — with control you can revoke.**

## Design accent

Red (`--accent-sentinel`). Secure-room chrome: serious, minimal, high contrast.
No “military-grade” overclaim.
